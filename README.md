# GRILLYAZH — официальный сайт

Одностраничный сайт артиста: новинка, музыка, концерты, галерея, заявка для организаторов и контакты.

## Что внутри

Стиль — продуктовые страницы Apple: много воздуха, крупная типографика, светлые и тёмные секции по очереди,
анимации привязаны к прокрутке.

- **Первый экран:** фото видно только сквозь буквы GRILLYAZH. При прокрутке камера «влетает» в букву I,
  фото раскрывается на весь экран и появляется «Выше градус.».
- **Новинка:** крупный заголовок с градиентом и студийный портрет на белом, который поднимается при прокрутке.
- **Жара:** обложка сингла «плывёт», как воздух в жару (собственный WebGL-шейдер). Чем дальше листаешь,
  тем сильнее эффект и выше температура: «Сделай громче» → «Ещё громче» → «Выше градус».
  Если навести курсор на обложку, она плывёт сильнее.
- **Музыка:** горизонтальная полка релизов со стрелками.
- **Концерты:** даты сами делятся на ближайшие и прошедшие. Если ближайших нет, показывается «Новые даты — скоро»
  со ссылкой на Telegram.
- **Фото:** сетка-бенто с параллаксом внутри плиток и полноэкранным просмотром.
- **Организаторам:** форма открывает Telegram менеджера и копирует текст заявки в буфер.
- Шапка сама становится светлой или тёмной под цвет секции.
- **Шрифты:** Inter (основной) и Oswald (логотип и цифры), оба из Google Fonts.
- **Анимации:** GSAP и ScrollTrigger, плавная прокрутка Lenis.
- При `prefers-reduced-motion` все сложные анимации отключаются, сайт остаётся полностью рабочим.

## Как обновлять контент

Весь контент лежит в `src/data.js`:

- `releases`: релизы. Чтобы кнопка «Слушать» вела на конкретный трек, вставьте ссылку в `url`.
- `concerts`: концерты. Дата в формате `2026-04-26T20:00:00+03:00`. Прошедшие концерты сами уходят в архив.
- `gallery`: фото галереи.
- `socials`, `manager`: ссылки и правила для менеджера.

Фото лежат в `public/photos/` в формате WebP. Замените файлы оригиналами с теми же именами:

| Файл | Что это |
|---|---|
| `fisheye.webp` | первый экран (фото в буквах) |
| `studio.webp` | студийный портрет на белом фоне в блоке «Новинка» |
| `cover-*.webp` | обложки релизов (квадрат, от 1500×1500) |
| `gallery-*.webp` | фото в сетке «Фото» и фон плитки концертов |
| `og.jpg` | превью ссылки в соцсетях (1200×630) |

`fisheye` и `studio` — оригиналы. Обложки и `gallery-*` пока вырезаны из видео старого сайта, их стоит заменить.

Перевести JPG в WebP: `cwebp -q 88 photo.jpg -o photo.webp` или любой онлайн-конвертер.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` (результат в `dist/`).

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает сайт и выкладывает его при каждом пуше.
Один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
