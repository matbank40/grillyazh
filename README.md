# GRILLYAZH — официальный сайт

Одностраничный сайт артиста: новинка, музыка, концерты, галерея, заявка для организаторов и контакты.

## Что внутри

Тёмная «кинематографичная» эстетика: огромный Oswald капсом, курсивная антиква Cormorant Garamond для акцентов,
подписи мелким капсом с разрядкой, тонкие линии, плёночное зерно.

- **Загрузка:** счётчик 000–100, затем занавес уходит вверх, а буквы GRILLYAZH встают на место.
- **Первый экран:** фото на WebGL с лёгким маревом. За курсором (или пальцем) остаётся «горячий след»:
  картинка плывёт и расслаивается по цветам. Логотип растянут ровно на всю ширину экрана.
- **Сингл:** «ВЫШЕ» и «ГРАДУС» разъезжаются в стороны, обложка раскрывается на весь экран, растворяется
  в размытии, и появляется кнопка «Слушать».
- **Манифест:** строки с фото прямо внутри текста едут навстречу друг другу.
- **Музыка:** список релизов; при наведении справа меняется обложка (на телефоне — при прокрутке).
- **Тур:** даты сами делятся на ближайшие и прошедшие. Если ближайших нет — бегущая строка «Новые даты скоро»
  и кнопка Telegram.
- **Кадры:** три колонки фото едут с разной скоростью, фото раскрываются шторкой, по клику — просмотр.
- **Букинг:** форма открывает Telegram менеджера и копирует текст заявки.
- **Мини-плеер** «Выше градус» внизу экрана: появляется после блока сингла и прячется у подвала.
- **Анимации:** GSAP и ScrollTrigger, плавная прокрутка Lenis, свой шейдер на чистом WebGL.
- При `prefers-reduced-motion` сложные анимации отключаются, сайт остаётся полностью рабочим.

## Как обновлять контент

Весь контент лежит в `src/data.js`:

- `releases`: релизы. Чтобы кнопка «Слушать» вела на конкретный трек, вставьте ссылку в `url`.
- `concerts`: концерты. Дата в формате `2026-04-26T20:00:00+03:00`. Прошедшие концерты сами уходят в архив.
- `gallery`: фото галереи.
- `socials`, `manager`: ссылки и правила для менеджера.

Фото лежат в `public/photos/` в формате WebP. Замените файлы оригиналами с теми же именами:

| Файл | Что это |
|---|---|
| `fisheye.webp` | первый экран и манифест |
| `studio.webp` | студийный портрет (манифест, кадры) |
| `cover-*.webp` | обложки релизов (квадрат, от 1500×1500) |
| `gallery-*.webp` | фото в блоке «Кадры» |
| `og.jpg` | превью ссылки в соцсетях (1200×630) |

`fisheye` и `studio` — оригиналы. Обложки и `gallery-*` пока вырезаны из видео старого сайта, их стоит заменить.

Перевести JPG в WebP: `cwebp -q 88 photo.jpg -o photo.webp` или любой онлайн-конвертер.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` (результат в `dist/`).

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает сайт и выкладывает его при каждом пуше.
Один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
